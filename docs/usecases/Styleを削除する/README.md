# Styleを削除する

## 主アクター
テーマ作者

## 目的
追加した表示スタイルを1つアプリの定義から取り除く。

## 前提
- アプリが起動している。
- 組み込みの表示スタイルは `Gauges` と `Bars` の2つで、削除できない。
- 削除の対象は、「Styleを追加する」で取り込んだ組み込み以外のスタイルだけである。
- テーマ作者は、追加元のフォルダーではなく、アプリ内の `Styles` 画面から操作する。

## 共通の受け入れ条件
- 画面の見出し、ボタン、エラーは英語で表示する。
