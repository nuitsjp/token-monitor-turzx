# Styleを削除する

- 種別: 主成功
- UI確認: 要

## 開始条件
組み込み以外の定義が1つ以上ある。

## 手順
| # | アクター | システム |
| --- | --- | --- |
| 1 | テーマ作者が `Styles` を開き、組み込み以外のカードの `Delete` を押す | 確認ダイアログを表示する。ダイアログには、そのスタイルの `name` と、`Delete`・`Cancel` を表示する |
| 2 | 確認ダイアログで `Delete` を押す | アプリ内部の `styles\<id>\` を削除し、定義から取り除く。`Styles` の一覧は、その時点の定義で作り直す |

## 受け入れ条件
- 削除したスタイルは定義から消え、一覧にカードが出ない。アプリを再起動しても戻らない。
- 削除の対象は、そのスタイルの内部コピー（`styles\<id>\`）だけである。追加元のフォルダー、ほかのスタイル、設定ファイルは変えない。
- `Gauges` と `Bars` のカードには `Delete` を置かず、定義にも残る。
- `Cancel` を押したときと、ダイアログを閉じたときは、定義も内部のファイルも変えない。
- 削除に失敗したときは、定義に残し、`Could not delete the style.` を表示する。ファイルの一部だけが消えた状態を残さない。
- 削除したスタイルと同じ `id` のフォルダーは、「Styleを追加する」で再び追加できる。
- TURZX へ送る画像と、現在の表示に使っているスタイルは変えない。
